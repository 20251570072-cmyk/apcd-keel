APCD-Keel: Modular Intelligence Platform for Ajman Port &amp; Customes
# KEEL 🚢⚓

**The Backbone of Smart Customs for Ajman Port & Customs Department (APCD)**

Built for the APCD AI Innovation Competition 2026.

## The Problem
Ajman Port clears cargo too slowly because every shipment is treated with equal suspicion. Officers waste time on manual document checks, and the port lacks predictive intelligence to prioritize inspections.

## The Solution
KEEL is a modular intelligence core that powers three operational modules:

| Module | Status | What It Does |
|---|---|---|
| **KEEL Trust** | 🟢 Live | Behavioral risk scoring for traders |
| **KEEL Circular** | 🟢 Live | AI-suggests circular economy partnerships |
| **KEEL Field** | 🟢 Live | Single-screen officer dashboard for port floor |
| KEEL Vision | 🟡 Roadmap | CV-based seal verification (Phase 2) |
| KEEL Routes | 🟡 Roadmap | AIS maritime tracking (Phase 2) |
| KEEL Flow | 🟡 Roadmap | Workflow RPA automation (Phase 3) |

## Why "KEEL"?
Every ship has a keel — the structural backbone that holds it upright. Dubai automates cranes. **APCD automates the keel** — the decisions that hold everything up.
